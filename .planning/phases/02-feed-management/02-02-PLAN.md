<task type="auto">
  <name>Task 1: Create CLI entry point and configure package.json</name>
  <files>src/cli.ts, package.json</files>
  <action>
**Create `src/cli.ts`** as the CLI entry point with these exact contents:

1. First line MUST be the shebang: `#!/usr/bin/env node`
2. Import `Command` from `commander`
3. Import all three register functions from `./commands/add.js`, `./commands/remove.js`, `./commands/list.js`
4. Create Commander program:
   ```
   const program = new Command();
   program
     .name('podcast-dl')
     .description('Download podcast episodes from RSS feeds')
     .version('0.1.0');
   ```
5. Register all commands: `registerAddCommand(program)`, `registerRemoveCommand(program)`, `registerListCommand(program)`
6. CRITICAL: Use `program.parseAsync(process.argv)` -- NOT `program.parse()`. The add command is async (fetches URL). Using `parse()` would silently exit before the fetch completes. This is the most common Commander + async mistake.

**Update `package.json`** with two additions:
1. Add `"bin"` field: `"bin": { "podcast-dl": "./dist/cli.js" }`
2. Add dev script: `"dev": "npx tsx src/cli.ts"` in the scripts object

ESM imports with `.js` extensions per project convention.
  </action>
  <verify>
Run `npx tsc --noEmit` to confirm TypeScript compiles cleanly. Run `npx tsx src/cli.ts --help` to confirm CLI displays help with add, remove, list commands. Run `npx tsx src/cli.ts --version` to confirm version output.
  </verify>
  <done>
src/cli.ts exists with shebang, Commander setup, all three commands registered, and parseAsync call. package.json has bin entry and dev script. `--help` shows all three commands.
  </done>
