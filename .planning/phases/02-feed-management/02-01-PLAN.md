  <name>Task 1: Install dependencies and create feed-validator service</name>
  <files>package.json, src/services/feed-validator.ts</files>
  <action>
Run `npm install commander feedsmith picocolors` and `npm install -D tsx` to add all Phase 2 dependencies.

Create `src/services/feed-validator.ts` exporting an async `validateFeed(url: string)` function that returns `Promise<{ title: string }>`. Implementation:

1. **Fetch the URL** using native `fetch` with:
   - `headers: { 'User-Agent': 'podcast-dl/0.1.0' }` (some servers reject bare requests)
   - `signal: AbortSignal.timeout(30_000)` (30s timeout to prevent indefinite hangs)
   - Catch fetch errors: if `error.name === 'TimeoutError'` throw "Request timed out"; otherwise throw "Failed to fetch URL: {message}"
   - If `!response.ok`, throw `HTTP {status} fetching {url}`

2. **Parse the response** with feedsmith's `parseFeed(content)`:
   - Import: `import { parseFeed } from 'feedsmith';`
   - Wrap in try/catch -- on failure throw "URL is not a valid RSS or Atom feed"

3. **Validate audio enclosures exist** (USER DECISION: only accept feeds with audio enclosures):
   - Access items from the parsed feed: `const items = (parsed.feed as any).items ?? (parsed.feed as any).entries ?? [];`
   - For RSS feeds, items have `enclosures` array. For Atom feeds, items have `links` array.
   - Check if ANY item has an audio enclosure:
     - RSS: `item.enclosures?.some(e => e.type?.startsWith('audio/'))`
     - Atom: `item.links?.some(l => l.type?.startsWith('audio/') && l.rel === 'enclosure')`
   - If NO item has audio enclosures, throw: "Feed is valid RSS but contains no audio enclosures. Only podcast feeds with audio content are supported."
   - This rejects video-only feeds and non-podcast RSS/Atom feeds per user decision.

4. **Extract and return the podcast title**:
   - Use fallback chain: `(parsed.feed as any).title ?? (parsed.feed as any).itunes?.title ?? 'Untitled Podcast'`
   - If title is empty string, use 'Untitled Podcast'
   - Return `{ title }`

Use ESM imports with `.js` extensions per project convention.
  </action>

  </verify>

<task type="auto">
  <name>Task 2: Create add, remove, and list command handlers</name>
  <files>src/commands/add.ts, src/commands/remove.ts, src/commands/list.ts</files>
  <action>
Create three command handler files. Each exports a `registerXCommand(program: Command)` function that registers a subcommand on the Commander program instance.

**`src/commands/add.ts`** -- `registerAddCommand(program)`:
- `.command('add').description('Subscribe to a podcast RSS feed').argument('<url>', 'RSS feed URL')`
- Action handler (async):
  1. Validate URL format: `try { new URL(url) } catch { error + exit(1) }` -- also check `protocol` is `http:` or `https:`
  2. Create feeds store: `const store = createFeedsStore(getFeedsPath())`
  3. Check duplicate: if `store.has(url)`, print yellow warning "Already subscribed: {url}" and exit(1)
  4. Call `validateFeed(url)` wrapped in try/catch -- on error, print red error message and exit(1)
  5. Create Feed object: `{ url, name: result.title, addedAt: new Date().toISOString() }`
  6. Call `store.add(feed)`
  7. Print green success: `Subscribed to "{feed.name}"`
- Imports: `Command` from commander, `pc` from picocolors, `validateFeed` from services, `createFeedsStore` from state, `getFeedsPath` from state/paths, `Feed` type

**`src/commands/remove.ts`** -- `registerRemoveCommand(program)`:
- `.command('remove').description('Unsubscribe from a podcast feed').argument('<url-or-name>', 'Feed URL or podcast name')`
- Action handler (sync -- no async needed):
  1. Create feeds store
  2. Get all feeds
  3. Find match: first try exact URL match (`f.url === identifier`), then case-insensitive name match (`f.name.toLowerCase() === identifier.toLowerCase()`)
  4. If no match, print red error "No feed found matching '{identifier}'" and exit(1)
  5. Call `store.remove(match.url)`
  6. Print green success: `Unsubscribed from "{match.name}"`

**`src/commands/list.ts`** -- `registerListCommand(program)`:
- `.command('list').description('List subscribed podcast feeds')`
- Action handler (sync):
  1. Create feeds store, get all feeds
  2. If empty: print yellow hint "No feeds subscribed. Use \"podcast-dl add <url>\" to get started." and return (USER DECISION: specific empty-state hint)
  3. Sort feeds alphabetically by name: `feeds.sort((a, b) => a.name.localeCompare(b.name))` (USER DECISION: alphabetical by name)
  4. Print each feed as name + URL (USER DECISION: no numbering, no date):
     ```
     {pc.cyan(feed.name)}
     {pc.dim(feed.url)}
     ```
     With a blank line between entries for readability.

All files use ESM imports with `.js` extensions. Import `type { Feed }` from `../types.js`.
