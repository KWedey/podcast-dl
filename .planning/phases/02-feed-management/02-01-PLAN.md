<task type="auto">
  <name>Task 2: Create feed-validator service and all command handlers</name>
  <files>src/services/feed-validator.ts, src/commands/add.ts, src/commands/remove.ts, src/commands/list.ts</files>
  <action>
Create four source files following the research patterns precisely:

1. **src/services/feed-validator.ts** -- RSS validation service (FEED-03 core):
   - Import `parseFeed` from `'feedsmith'`
   - Export interface `FeedValidationResult` with `title: string`, `itemCount: number`
   - Export async function `validateFeed(url: string): Promise<FeedValidationResult>`
   - Implementation:
     a. Fetch the URL with `fetch(url, { headers: { 'User-Agent': 'podcast-dl/0.1.0' }, signal: AbortSignal.timeout(30_000) })`
     b. Wrap fetch in try/catch: on TimeoutError (`error.name === 'TimeoutError'`), throw `new Error('Request timed out fetching <url>')`. On other errors, throw `new Error('Failed to fetch <url>: <message>')`
     c. Check `response.ok` -- if false, throw `new Error('HTTP <status> fetching <url>')`
     d. Get content via `response.text()`
     e. Call `parseFeed(content)` wrapped in try/catch -- on catch, throw `new Error('URL is not a valid RSS feed')`
     f. Extract title: use `(feed as { title?: string }).title` with fallback to `'Untitled Podcast'` if empty/undefined. NOTE: feedsmith's parseFeed returns `{ format, feed }` where `feed` is a format-specific type. Cast feed to access `.title`.
     g. Extract item count: `((feed as { items?: unknown[] }).items || []).length`
     h. Return `{ title, itemCount }`

2. **src/commands/add.ts** -- Add feed command (FEED-01):
   - Import `Command` from `'commander'`
   - Import `pc` from `'picocolors'` (default import)
   - Import `validateFeed` from `'../services/feed-validator.js'`
   - Import `createFeedsStore` from `'../state/feeds-store.js'`
   - Import `getFeedsPath` from `'../state/paths.js'`
   - Import type `Feed` from `'../types.js'`
   - Export function `registerAddCommand(program: Command): void`
   - Register `.command('add').description('Subscribe to a podcast RSS feed').argument('<url>', 'RSS feed URL')`
   - Async `.action(async (url: string) => { ... })`
   - Action handler steps:
     a. Validate URL format: try `new URL(url)`, catch -> `console.error(pc.red('Error: Invalid URL'))` + `process.exit(1)`. Check protocol is http: or https: -- if not, error + exit.
     b. Create store: `const store = createFeedsStore(getFeedsPath())`
     c. Check duplicate: if `store.has(url)`, print `pc.yellow('Feed already subscribed: ' + url)` + `process.exit(1)`
     d. Validate feed: `const result = await validateFeed(url)` -- wrap in try/catch, on error print `pc.red('Error: ' + error.message)` + `process.exit(1)`
     e. Build feed object: `{ url, name: result.title, addedAt: new Date().toISOString() }`
     f. `store.add(feed)`
     g. Print `pc.green('Subscribed to "' + feed.name + '"')`

3. **src/commands/remove.ts** -- Remove feed command (FEED-02):
   - Import `Command` from `'commander'`
   - Import `pc` from `'picocolors'`
   - Import `createFeedsStore` from `'../state/feeds-store.js'`
   - Import `getFeedsPath` from `'../state/paths.js'`
   - Export function `registerRemoveCommand(program: Command): void`
   - Register `.command('remove').description('Unsubscribe from a podcast feed').argument('<url-or-name>', 'Feed URL or podcast name')`
   - `.action((identifier: string) => { ... })` (synchronous -- no async needed)
   - Action handler:
     a. `const store = createFeedsStore(getFeedsPath())`
     b. `const feeds = store.getAll()`
     c. Find match: `feeds.find(f => f.url === identifier || f.name.toLowerCase() === identifier.toLowerCase())`
     d. If no match: `console.error(pc.red('No feed found matching "' + identifier + '"'))` + `process.exit(1)`
     e. `store.remove(match.url)`
     f. Print `pc.green('Unsubscribed from "' + match.name + '"')`
   - Per research decision: do NOT purge download history when removing a feed. Only remove from feeds.json.

4. **src/commands/list.ts** -- List feeds command:
   - Import `Command` from `'commander'`
   - Import `pc` from `'picocolors'`
   - Import `createFeedsStore` from `'../state/feeds-store.js'`
   - Import `getFeedsPath` from `'../state/paths.js'`
   - Export function `registerListCommand(program: Command): void`
   - Register `.command('list').description('List subscribed podcast feeds')`
   - `.action(() => { ... })` (synchronous)
   - Action handler:
     a. `const store = createFeedsStore(getFeedsPath())`
     b. `const feeds = store.getAll()`
     c. If `feeds.length === 0`: print `pc.yellow('No feeds subscribed. Use "podcast-dl add <url>" to add one.')` + return
     d. Print `pc.bold('Subscribed feeds (' + feeds.length + '):')` then blank line
     e. For each feed: print `'  ' + pc.cyan(feed.name)` then `'  ' + pc.dim(feed.url)` then blank line

CRITICAL: All local imports MUST use `.js` extension (e.g., `'../services/feed-validator.js'`). This is required by NodeNext module resolution.
