**src/state/history-store.ts** -- Enhance `createHistoryStore` to work with the new `HistoryEntry`-based format:

3. Update `markDownloaded(feedUrl, guid)` to upsert: if an entry with the same guid exists (e.g., previously failed), update its status to `'downloaded'`; otherwise push a new entry.

4. Update `getDownloadedGuids(feedUrl)` to filter for `status === 'downloaded'` entries and return just the guid strings.

5. Add `isFailed(feedUrl, guid): boolean` -- returns true if entry exists with `status === 'failed'`.

6. Add `markFailed(feedUrl, guid): void` -- upserts entry with `status: 'failed'` (same upsert pattern as markDownloaded).

Import `HistoryEntry` and `DownloadHistory` from types.ts.

<task type="auto">
  <name>Task 2: Create RSS parser and episode downloader services</name>
  <files>src/services/rss-parser.ts, src/services/episode-downloader.ts</files>
  <action>
**src/services/rss-parser.ts** -- Create a `fetchEpisodes(url: string): Promise<Episode[]>` function:

1. Fetch the RSS feed URL with `User-Agent: 'podcast-dl/0.1.0'` header and 30-second timeout via `AbortSignal.timeout(30_000)`.
2. Parse content with feedsmith's `parseFeed()`. Access `feed.items` from the parsed result (cast feed as needed, following the pattern in `feed-validator.ts`).
3. For each item, find the first enclosure with `type === 'audio/mpeg'` (not just `startsWith('audio/')` -- only accept MP3-compatible enclosures per research recommendation on non-MP3 pitfall). If no `audio/mpeg` enclosure, skip the item.
4. Extract guid from `item.guid?.value`, falling back to the enclosure URL if guid is missing.
5. Extract title from `item.title`, defaulting to `'Untitled Episode'`.
6. Parse pubDate using `new Date(item.pubDate)` -- if invalid or missing, set `publishedAt` to `null`.
7. Return `Episode[]` with `{ guid, title, audioUrl, mimeType, publishedAt }`.
8. Let errors from fetch/parse propagate to the caller (the download command handles error display).

Import `Episode` from `../types.js`.

**src/services/episode-downloader.ts** -- Create a `downloadEpisode(audioUrl: string, destPath: string): Promise<DownloadResult>` function:

1. Define and export `DownloadResult` interface: `{ success: boolean; error?: string }`.
2. Set `tmpPath = destPath + '.tmp'`.
3. Ensure parent directory exists with `mkdir(dirname(destPath), { recursive: true })`.
4. Fetch the audio URL with `User-Agent: 'podcast-dl/0.1.0'` and 5-minute timeout (`AbortSignal.timeout(300_000)`).
5. Check `response.ok` and `response.body` (return failure result if either fails).
6. Convert to Node.js stream: `Readable.fromWeb(response.body as ReadableStream<Uint8Array>)` -- use type assertion with `ReadableStream` imported from `node:stream/web` to handle the TypeScript type mismatch (Pitfall 1 from research).
7. Pipe via `pipeline(nodeStream, createWriteStream(tmpPath))`.
8. On success: `rename(tmpPath, destPath)` and return `{ success: true }`.
9. On error (catch block): attempt `unlink(tmpPath)` (silently ignore if tmp doesn't exist), return `{ success: false, error: message }`.

Use imports from `node:fs` (createWriteStream), `node:fs/promises` (rename, unlink, mkdir), `node:stream/promises` (pipeline), `node:stream` (Readable), `node:path` (dirname), and `node:stream/web` (ReadableStream type).
  </action>
