  <action>
Create `src/commands/download.ts` exporting `registerDownloadCommand(program: Command): void` following the established `registerXCommand` pattern.

The download command action (async) implements the full pipeline:

**1. Initialize stores and state:**
- Create feedsStore from `getFeedsPath()`, historyStore from `getHistoryPath()`, get `downloadsDir` from `getDownloadsDir()`.
- If no feeds subscribed, print yellow message "No feeds subscribed. Use \"podcast-dl add <url>\" to get started." and return.
- Sort feeds alphabetically by name (`.sort((a, b) => a.name.localeCompare(b.name))`).
- Initialize counters: `totalDownloaded = 0`, `totalSkipped = 0`, `totalFailed = 0`, `feedsReached = 0`, `failedEpisodes: Array<{ feed: string; title: string }> = []`.

**2. For each feed (sequential):**
- Print feed header: `\n` + bold cyan feed name using picocolors.
- Fetch episodes with `fetchEpisodes(feed.url)`. On error: print indented red error message, continue to next feed.
- Increment `feedsReached` on success.
- Filter episodes using a `filterEpisodes` helper function (defined in this file):
  - Remove episodes where `historyStore.isDownloaded(feed.url, ep.guid)` is true.
  - Log each skipped episode: `  Skipping: Episode Title (already downloaded)` in dim text.
  - Sort remaining by publishedAt descending (newest first). Episodes with null publishedAt sort to end.
  - Take first 5 (MAX_EPISODES_PER_FEED constant = 5).
  - Reverse for oldest-first download order per user decision.
- If no new episodes after filtering, print `  No new episodes` in dim text and continue.

**3. For each episode in filtered list (sequential within feed):**
- Build destination path using a `buildEpisodePath` helper function (defined in this file):
  - `const dirName = sanitizeDirName(feed.name)`
  - `const datePrefix = episode.publishedAt ? new Date(episode.publishedAt).toISOString().slice(0, 10) : 'unknown-date'`
  - `const sanitizedTitle = sanitizeFilename(episode.title).slice(0, 80)` (truncate at 80 chars per user decision)
  - `const filename = \`${datePrefix}_${sanitizedTitle}.mp3\``
  - Return `join(downloadsDir, dirName, filename)`
- Print `  Downloading: Episode Title...` in white text.
- Call `downloadEpisode(episode.audioUrl, destPath)`. If failed, retry once (call downloadEpisode again).
- On success: call `historyStore.markDownloaded(feed.url, episode.guid)`, print `  Downloaded: Episode Title` in green, increment `totalDownloaded`.
- On failure (after retry): call `historyStore.markFailed(feed.url, episode.guid)`, print `  Failed: Episode Title (error message)` in red, increment `totalFailed`, push to `failedEpisodes`.

**4. End-of-run summary:**
- If `feedsReached === 0` and feeds existed, print bold red: "No feeds could be reached -- check your connection".
- Print `\n` + bold "Summary".
- Print `  Downloaded: N` (green number).
- Print `  Skipped:    N` (dim number).
- Print `  Failed:     N` (red number, or dim 0 if none).
- If failedEpisodes is non-empty, print `\nFailed episodes:` in red, then each as `  - FeedName: Episode Title`.

**5. Exit code:**
- If `totalFailed > 0`, call `process.exit(1)`.

**Imports:**
- `Command` from `commander`
- `pc` from `picocolors`
- `join` from `node:path`
- `createFeedsStore` from `../state/feeds-store.js`
- `createHistoryStore` from `../state/history-store.js`
- `getFeedsPath, getHistoryPath, getDownloadsDir` from `../state/paths.js`
- `fetchEpisodes` from `../services/rss-parser.js`
- `downloadEpisode` from `../services/episode-downloader.js`
- `sanitizeFilename, sanitizeDirName` from `../utils/sanitize.js`
- `Episode` type from `../types.js`

Note: The `filterEpisodes` and `buildEpisodePath` helper functions are module-private (not exported). They are defined in this file as standalone functions, not inside the action handler.
