<task type="auto">
  <name>Task 2: Create type definitions, atomic write helper, and path resolution</name>
  <files>src/types.ts, src/state/atomic-write.ts, src/state/paths.ts</files>
  <action>
Create three source files following the research code examples exactly:

1. **src/types.ts** -- Shared TypeScript interfaces:
   - `Feed` interface: `url: string`, `name: string`, `addedAt: string` (ISO 8601)
   - `DownloadHistory` type: `Record<string, string[]>` (feed URL -> array of GUIDs)
   - `Episode` interface: `guid: string`, `title: string`, `audioUrl: string`, `mimeType: string`, `publishedAt: string | null`
   - Export all three types

2. **src/state/atomic-write.ts** -- Atomic write helper:
   - Import `writeFileSync`, `renameSync`, `mkdirSync` from `node:fs`
   - Import `dirname` from `node:path`
   - Export function `atomicWriteSync(filePath: string, data: string): void`
   - Implementation: `mkdirSync(dirname(filePath), { recursive: true })`, write to `filePath + '.tmp'` with `{ encoding: 'utf-8', flush: true }`, then `renameSync` temp to final path
   - Temp file MUST be in same directory as target (not /tmp) to avoid EXDEV cross-device errors

3. **src/state/paths.ts** -- Data directory resolution:
   - Import `join` from `node:path`, `homedir` from `node:os`
   - Export `getDataDir()`: returns `join(homedir(), '.podcast-dl')`
   - Export `getFeedsPath()`: returns `join(getDataDir(), 'feeds.json')`
   - Export `getHistoryPath()`: returns `join(getDataDir(), 'history.json')`

IMPORTANT: All imports between local files MUST use `.js` extension (e.g., `import { atomicWriteSync } from './atomic-write.js'`). This is required by NodeNext module resolution -- TypeScript resolves .js imports to .ts source files at compile time.
  </action>
  <verify>
Run `npx tsc --noEmit` -- should compile with zero errors.
Run `npx tsc` to produce dist/ output, then run `node -e "import('./dist/state/atomic-write.js').then(m => console.log(typeof m.atomicWriteSync))"` -- should print "function".
Run `node -e "import('./dist/state/paths.js').then(m => console.log(m.getDataDir()))"` -- should print a path ending in `.podcast-dl`.
  </verify>
  <done>types.ts exports Feed, DownloadHistory, Episode. atomic-write.ts exports atomicWriteSync using writeFileSync flush:true + renameSync. paths.ts exports getDataDir, getFeedsPath, getHistoryPath pointing to ~/.podcast-dl/.</done>
