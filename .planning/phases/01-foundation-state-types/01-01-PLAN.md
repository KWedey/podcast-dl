<task type="auto">
  <name>Task 2: Create type definitions, atomic write helper, and path resolution</name>
  <files>src/types.ts, src/state/atomic-write.ts, src/state/paths.ts</files>
  <action>
Create three source files:

1. **src/types.ts** -- Shared TypeScript interfaces:
   - `Feed` interface: `url: string`, `name: string`, `addedAt: string` (ISO 8601)
   - `DownloadHistory` type: `Record<string, string[]>` (feed URL -> array of GUIDs)
   - `Episode` interface: `guid: string`, `title: string`, `audioUrl: string`, `mimeType: string`, `publishedAt: string | null`
   - Export all three types

2. **src/state/atomic-write.ts** -- Atomic write helper using `write-file-atomic` library (per user decision -- do NOT hand-roll with writeFileSync+renameSync):
   - Import `writeFileAtomicSync` from `write-file-atomic` (check the library's actual export name -- may be default export with `.sync` method or named export)
   - Import `mkdirSync` from `node:fs`
   - Import `dirname` from `node:path`
   - Export function `atomicWriteSync(filePath: string, data: string): void`
   - Implementation: `mkdirSync(dirname(filePath), { recursive: true })` to ensure parent dir exists, then call write-file-atomic's sync function with the filePath and data
   - This wraps write-file-atomic so consumers have a single import and don't need to know about the library

3. **src/state/paths.ts** -- Project-relative data directory resolution (per user decision: "Everything stays within the project directory -- nothing touches ~/"):
   - Import `join`, `resolve` from `node:path`
   - Import `fileURLToPath` from `node:url`
   - Do NOT import `homedir` from `node:os` -- user explicitly locked: no system-wide paths
   - Derive the project root using `resolve(fileURLToPath(import.meta.url), '..', '..', '..')` to get from `src/state/paths.ts` up to the project root. Alternatively, use `process.cwd()` -- either approach is fine as long as it resolves to the project directory.
   - Export `getDataDir()`: returns `join(projectRoot, 'data')` -- project-relative `data/` subdirectory
   - Export `getFeedsPath()`: returns `join(getDataDir(), 'feeds.json')`
   - Export `getHistoryPath()`: returns `join(getDataDir(), 'history.json')`

IMPORTANT: All imports between local files MUST use `.js` extension (e.g., `import { atomicWriteSync } from './atomic-write.js'`). This is required by NodeNext module resolution -- TypeScript resolves .js imports to .ts source files at compile time.
  </action>

  </verify>
